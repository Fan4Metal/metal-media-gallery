# Metal Media Gallery

[English](README.md) · **Русский**

Плагин для Obsidian, который превращает callout'ы в галереи изображений в режиме чтения — **без обрезки**. Портретные и альбомные фото стоят рядом, каждое показано целиком.

![gallery](https://img.shields.io/badge/Obsidian-plugin-7c3aed) ![view](https://img.shields.io/badge/режим-чтение-blue)

![Justified-галерея в режиме чтения Obsidian](images/screenshot.png)

## Возможности

- **`[!gallery]` — justified-ряды.** Ширины вычисляются на JavaScript пропорционально соотношению сторон каждой картинки, поэтому каждый ряд заполняет ширину от края до края, при этом ничто не растягивается и не обрезается (как в Google Photos / Flickr).
- **`[!gallery-masonry]` — колонки масонри.** Стиль Pinterest; каждая картинка показана целиком в натуральную высоту.
- **Никакой обрезки.** Портреты и альбомные снимки свободно смешиваются.
- **Пересчёт раскладки** при изменении ширины панели и по мере загрузки картинок.
- **Шире текстовой колонки** — галерея выходит за пределы читаемой ширины строки (настраивается).
- **Совместимость с лайтбоксом** — работает с плагином [Metal Image Viewer](https://github.com/Fan4Metal/metal-image-viewer) для клика-по-картинке.

## Использование

Вложения оборачиваются в callout, а картинки помещаются внутрь. Пустые строки между картинками не важны.

```markdown
> [!gallery]
> ![[photo-1.png]]
> ![[photo-2.png]]
> ![[photo-3.png]]
> ![[photo-4.png]]
```

Вариант масонри:

```markdown
> [!gallery-masonry]
> ![[photo-1.png]]
> ![[photo-2.png]]
> ![[photo-3.png]]
```

> **Совет:** одиночную картинку достаточно вставить как обычно (вне callout) — галерея нужна для групп.

### Команда быстрого оборачивания

Вместо ручного набора callout'а достаточно выделить строки с картинками и запустить команду:

- **Metal Media Gallery: Wrap selection in gallery callout**
- **Metal Media Gallery: Wrap selection in masonry gallery callout**
- **Metal Media Gallery: Remove gallery callout wrapping**

Нужная команда запускается из палитры команд (`Ctrl/Cmd+P`); также ей можно назначить горячую клавишу в **Settings → Hotkeys**. Каждая выделенная строка получит префикс `> `, а сверху добавится заголовок `> [!gallery]`. Если ничего не выделено — обернётся текущая строка. Команды всегда работают с целыми строками, даже если выделение начинается или заканчивается посреди строки.

> **Добавление в существующую галерею.** Если выделение захватывает строки уже существующей галереи или примыкает к ней сверху либо снизу, новые строки просто вливаются в неё (получают префикс `> `) — новый заголовок не добавляется и вложенной галереи не возникает. Заголовок остаётся первой строкой, тип берётся из него. Выделение, захватывающее две галереи, объединяет их в одну. Новая галерея с `> [!gallery]` создаётся только когда выделение *не* затрагивает другую галерею.

**Снятие обёртки** убирает заголовок `[!gallery]` и один уровень `> ` со всей галереи — достаточно поставить курсор в любое место внутри неё; при выделении снимается обёртка со всех затронутых галерей. Другие callout'ы и цитаты не затрагиваются.

Есть также **кнопка на ленте** (левая панель, иконка сетки): после выделения строк с картинками нажатие кнопки предлагает выбор *Justified*, *Masonry* или *Remove gallery*. Скрыть кнопку можно в **Settings → Metal Media Gallery → Ribbon button**.

## Настройки

Настройки расположены в **Settings → Metal Media Gallery**:

| Настройка | Что делает | По умолчанию |
| --- | --- | --- |
| Row height (justified) | Целевая высота ряда для `[!gallery]` | 220 px |
| Columns (masonry) | Максимальное число колонок для `[!gallery-masonry]` | 3 |
| Min column width (masonry) | На узких панелях и телефоне колонок становится меньше, чтобы каждая была не уже этого значения | 180 px |
| Gap | Зазор между элементами | 7 px |
| Border radius | Радиус скругления картинок/видео | 6 px |
| Gallery width | Ширина относительно текстовой колонки (нужен *Readable line length*) | 140% |

## Как работает justified-раскладка

Картинки группируются в ряды: элементы добавляются, пока следующий не перестанет помещаться на целевой высоте. Этот элемент либо втискивается в ряд, либо начинает следующий — выбирается вариант, при котором высота ряда ближе к целевой. Каждый полный ряд масштабируется так, чтобы ширины — каждая пропорциональна соотношению сторон — заполнили ряд точно. Поскольку ширина равна `соотношение_сторон × высота`, каждая картинка сохраняет истинные пропорции: без обрезки. Последний неполный ряд остаётся на целевой высоте и прижимается влево. Соотношения сторон запоминаются для каждой картинки, поэтому при возврате в заметку раскладка верна ещё до повторной загрузки картинок.

## Требования

- Работает в **режиме чтения**.
- **Ширина галереи > 100%** требует включённого *Settings → Editor → Readable line length*.

## Установка

Плагина пока нет в каталоге сообщества, поэтому установка выполняется вручную:

1. Загрузить `metal-media-gallery.zip` из [последнего релиза](https://github.com/Fan4Metal/metal-media-gallery/releases/latest) и распаковать его в `<хранилище>/.obsidian/plugins/`. В результате появится папка `<хранилище>/.obsidian/plugins/metal-media-gallery/` с тремя файлами плагина.
   *Как вариант*, можно создать эту папку вручную и скопировать в неё `manifest.json`, `main.js` и `styles.css` (из релиза или из корня этого репозитория).
2. Открыть **Settings → Community plugins**. Если включён *Restricted mode*, его следует выключить.
3. Нажать **Reload plugins** (или перезапустить Obsidian), найти в списке **Metal Media Gallery** и включить.
4. *(Рекомендуется)* Включить **Settings → Editor → Readable line length**, чтобы галереи могли быть шире текстовой колонки.

> **Примечание:** `.obsidian` — скрытая папка. Показ скрытых файлов включается в проводнике, либо папку можно открыть через **Settings → About → Open vault folder** в Obsidian, а затем перейти в `.obsidian/plugins`.

## Разработка

Исходники плагина (`manifest.json`, `main.js`, `styles.css`) лежат в корне репозитория. Для локального тестирования используется хранилище `dev_vault/` (в репозиторий не входит).

```powershell
# копирует файлы плагина в dev_vault и включает плагин
./deploy.ps1

# автодеплой при каждом изменении
./deploy.ps1 -Watch

# деплой в другое хранилище
./deploy.ps1 -Vault "C:\Path\To\Vault"
```

После деплоя следует перезагрузить Obsidian (`Ctrl+P → Reload app without saving`) и включить **Metal Media Gallery** в *Settings → Community plugins*.

Для алгоритма упаковки рядов есть небольшой набор тестов без зависимостей: `node --test`.

### Релиз

```powershell
# собирает dist/metal-media-gallery.zip (готовая к распаковке папка плагина)
./release.ps1
```

Предварительно увеличивается `version` в `manifest.json` и добавляется в `versions.json`. Скрипт выводит команду `gh release create`; тег релиза должен совпадать с версией, а три файла прикладываются к релизу отдельно от архива, потому что установщик Obsidian скачивает их по одному.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `manifest.json` | Манифест плагина |
| `versions.json` | Версия плагина → минимальная версия Obsidian |
| `main.js` | Пост-процессор + алгоритм justified-раскладки |
| `styles.css` | Оформление callout'а, вынос по ширине, масонри |
| `deploy.ps1` | Копирует плагин в хранилище; режим `-Watch` |
| `release.ps1` | Собирает `dist/metal-media-gallery.zip` для релиза |
| `test/pack.test.js` | Тесты алгоритма упаковки рядов (`node --test`) |
